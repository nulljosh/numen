Numen

A calculator that keeps its work. Write expressions anywhere on a canvas, click one result to feed it into another, and every number downstream updates the moment you change your mind.

Made for the sums you do more than once

Linked numbers

Click any result to drop a live reference into whatever you are typing. Edit the source and the whole chain recomputes.

An infinite canvas

Click empty space to start a new calculation, then drag it wherever it belongs. Nothing scrolls off into history.

Label everything

Give each number a name so the page still makes sense next week. It reads like a spreadsheet without the grid.

Graph any expression

Put an x in an expression and plot it. The curve redraws as its inputs change.

Works offline

Everything runs in the browser and saves on your device. No account, no network, no data leaving the page.

Free and open source

No ads, no purchases. Around 400 lines, its own parser, and the source is on GitHub.

Try a calculation

It opens straight in the browser with an example on the canvas. Nothing to download.
